# Exports J15 régionaux

Réexécuter les blocs 1–13 du nouveau notebook J15a après avoir copié le code.
Le manifeste doit être de version 2. Les contours communes_idf.geojson et
iris_idf.geojson conservent tous les territoires du profil. Les transports
et restaurants sont filtrés à l’affichage autour de la commune/IRIS choisi.
Ne pas mélanger les fichiers d’anciennes et nouvelles préparations : le lecteur
vérifie les empreintes de la version publiée.
